To let everyone in the house check off their own name on their phones and see updates live in real-time, paste a free Firebase Realtime Database URL below.

Quick 2-Minute Free Setup:
  1. Go to console.firebase.google.com and click Create a project.
  2. In the left menu, click Build → Realtime Database → Create Database.
  3. Choose Start in Test Mode and copy your database URL (looks like https://your-project-default-rtdb.firebaseio.com).
  4. Paste that URL below and click Connect Live Sync!
